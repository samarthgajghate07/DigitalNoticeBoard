# Digital Notice Board System

## Project Overview
The Digital Notice Board System is a Python application used to manage college notices. It uses SQLite to store notice information.

## Features
- View all notices
- Add new notices
- Update existing notices
- Delete notices with confirmation
- Search notices by title
- Filter notices by category
- Validate user input and dates

## Technologies Used
- Python
- SQLite Database
- Git
- GitHub

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run `python main.py`.

- Academic

- Events
- Sports
- General
